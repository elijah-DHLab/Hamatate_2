# ארכיון המטאטא — גרסה 2.2

## עקרונות
- ברירת המחדל בארכיון: מהדורות זמינות; המשתמש רשאי להציג את כל רשומות A.
- לוגו היסטורי: גזיר מסריקת התכנייה המקורית של ההצגה, `media/hamatate_historic_mark.png`.
- אודות: שלוש פסקאות תוכן ריקות (אודות המטאטא, אודות הפרויקט, שותפים) ומפת ידע כללית שהועברה מן המהדורה.
- המחזה נפתח בקריאה, עם הזמנה בולטת להצגת רשתות התוכן, משטח XML וחיי שחקנים.
- הערות שוליים: מצב תצוגה עצמאי, הערות בצד הטקסט עם לחיצה על ההפניה. הטקסט וההערות לא שונו.
- מפתח סימנים: דוגמאות חזותיות הממחישות מחיקה, צבע, רקע והבדלים בין שכבות.
- נשמרו מנוע הקריאה, השוואת הסדרים, V2 בחירות מרובות, רשתות, חומרים, נתונים ובדיקות.

## לוגואים
סמל אוניברסיטת חיפה נטען מכתובת ציבורית של המוסד; סמל המעבדה נטען מכתובת ציבורית של מעבדת אליהו. כאשר לא ניתן לגשת לתמונות, מוצג כיתוב חלופי נגיש. כדאי להחליף לקבצים מורשים מקומיים לפני הפקה סופית כדי שהסמלים יהיו זמינים גם ללא אינטרנט.

## הפעלה
`python -m http.server 8000` מתוך הספרייה ואז `http://localhost:8000`. קובץ standalone עצמאי מצורף בנפרד.
