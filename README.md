# ארכיון המטאטא — גרסת מאגר GitHub Pages

## פרסום
העלו **את תוכן תיקייה זו** לשורש הענף `main` במאגר `Hamatate_2`. ב־Settings → Pages בחרו `Deploy from a branch`, `main`, `/(root)`.
האתר פועל תחת `https://elijah-dhlab.github.io/Hamatate_2/` משום שכל הנתיבים הם יחסיים לבסיס האתר, ללא קידומת `/`.

## מבנה
- `index.html` — נקודת כניסה משותפת.
- `assets/css`, `assets/js`, `assets/branding` — הממשק וכללי העיצוב המשותפים לכל ההצגות.
- `corpus/data` — נתוני קטלוג, מזהי הצגות ואינדקס כלל־ארכיוני.
- `corpus/sources` — צילום גיליון MD של כלל ההצגות.
- `productions/A228401/data` — אינדקסים ונתונים נגזרים למהדורה.
- `productions/A228401/sources` — XML וקובצי התיוג המקוריים.
- `productions/A228401/media` — תכנייה ומקורות חזותיים.
- `productions/A228401/manifest.json` — מפת הנתונים של ההצגה.
- `scripts` — סקריפטי חילוץ/סנכרון, `schemas` — מקום לכללי TEI עתידיים; `docs` — תיעוד.

## היקף ההמרה
הממשק הקיים של V2.2, לרבות שכבות, בחירה מרובה, רשתות, השוואת סדרים, תוכנייה ומפת קורפוס, נשמר. שינוי זה מארגן מחדש את קבצי ההפצה ואת נתיביהם; **אין בכך עדיין מנוע רב־הצגתי גנרי**. ה־JS של המהדורה עדיין מכיר במיוחד את `A228401`. תוספת מהדורה מחייבת בעתיד טעינה דינמית של manifest ונתונים.

## בדיקה מקומית
`python -m http.server 8000` מתוך שורש המאגר וכניסה ל־`http://localhost:8000/`.
