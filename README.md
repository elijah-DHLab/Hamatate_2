# המטאטא — ארכיון ומהדורה מקושרת · 2.4

הפצה זו ממשיכה את האתר הקיים. היא אינה מחליפה את המהדורה באפליקציית גרפים נפרדת.

## פתיחה ופרסום

`index.html` נמצא בשורש החבילה. יש להעלות את **תוכן** קובץ ה־ZIP לשורש מאגר GitHub Pages, ולא תיקייה עוטפת. קובץ `.nojekyll` כלול. אין צורך בבנייה ב־Node או בהתקנת ספריות בדפדפן.

לבדיקה מקומית מתוך שורש החבילה:
```sh
python -m http.server 8000
```
פותחים `http://localhost:8000/`. גרסת ה־Standalone נבנית מאותם קבצים, עם הצהרה מפורשת שמדובר בצילום נתונים מוטמע ולא בשרת API חי.

## היכן נמצאות האפשרויות

נכנסים להצגה מתוך הארכיון ומתחילים בקריאה. ליד מתגי **רשתות התוכן / שכבות הכתיבה / דוברים** נמצא כפתור **מפת הרשתות והזרימה**. גם בניווט הקבוע נמצא **קריאה מרחוק · רשתות**.

הגרף הוא התצוגה הראשונה של הקריאה מרחוק. ניתן לצרף רשתות, לבחור מילים מתוכן, להציג מילים בגרף, לעבור לזרימה לאורך המחזה, למשטח הטקסט או לחפיפות. בחירה אינה מאפסת רשתות קודמות. רשימות המילים סגורות תחילה.

רשימת הראיות מתחת לגרף מחזירה לפסקה ולמיקום ההערה או המילה. בקריאה נמצאים גם „הקודם”, „הבא” ורשימת מקורות. ניתן להסתיר הערות שוליים בנפרד מהכתיבה ומהרשתות.

כלי השחקנים, תרחישים והשוואת סדרים, החומרים, המפות הקודמות והנתונים נשמרו. כלי מחקר קודמים זמינים גם תחת „כל כלי המחקר הקיימים”, בלי לדחוק את הגרף החדש לשם.

## שלושה מעמדי נתונים שאין לערבב

1. **סיווג מפורש בהערת מהדיר** — כגון „אזכור מסורת יהודית”. הראיה היא הערה מסוימת וההפניה שלה.
2. **מושג/נושא שנכתב בהערה** לעומת **מילים ליד ההפניה** — אלה אינם אותו דבר. הקשר שאינו נושא מפורש מסומן במסגרת מקווקוות; הוא אינו מוצג כטווח תיוג מאומת.
3. **רשת חיפוש מילולי** — הגדרת שאילתה מחקרית. התאמה למילה אינה הוכחה להשתייכות מאושרת לרשת שיח.

נוסחי 529 הערות המקור נשמרים בשלמותם. ההמרה לגופי ידע מוסיפה שכבה נגזרת; אינה עורכת את המקור.

## API — מה ממומש ומה לא

שכבת הידע החדשה יכולה להיטען מספק קבצים סטטי, מספק נתונים מוטמע, או מספק API עמודי המחזיר את אותו חוזה JSON. אין בהפצה שרת API חי. לא נמסר endpoint חי, ולכן בדיקות ספק ה־API נעשו עם תגובות מדומות לבדיקת תוכנה בלבד, לא עם תיוגים שמוצגים לקורא.

מנועי המהדורה הוותיקים עדיין מכילים התאמות ל־A228401. שכבת הידע מופרדת מהם באמצעות מזהים וחוזה נתונים, אך לא נטען שכל האתר כבר גנרי לכל מחזה. פרטים ב־`docs/DATA_API_CONTRACT.md`.

## לוגואים וקובצי הפצה

הלוגו ההיסטורי המקומי נשמר. קישורי הלוגואים המוסדיים הקיימים הועברו לשורת הכותרת. הם עדיין תמונות חיצוניות עם כיתוב חלופי; לא הוטמעו קובצי לוגו שלא אומתו. קובצי פונט אינם כלולים. החבילה אינה כוללת צילומי מסך, דוחות גרסאות ישנים או קובצי בדיקה מלאכותיים.
