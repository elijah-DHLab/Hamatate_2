## מה תוקן

1. **תרגום המעטפת:** הוסרה שגיאה שגרמה לאתחול התרגום להיכשל. סרגלי ניווט, כותרות, לחצנים, פילטרים, כלי קריאה וקריאה מרחוק, רכיבי קריאה בתוך המהדורה, הודעות רלוונטיות ומאפייני נגישות מתחלפים כעת. רכיבים שנוצרים מחדש בעקבות שינוי בחירה עוברים אף הם תרגום. הטקסטים ההיסטוריים, שמות אנשים, שמות מונחים וערכי המקור נותרים בשפת המקור.
2. **זום פרופורציונלי:** הגודל של **ה־SVG כולו** משתנה, במקום להגדיל רק צמתים או רק רוחב. צירים, קווים, תוויות וצמתים גדלים יחד. תצוגות רשתות, מונחים, זרימה ושחקנים כוללות אזור גלילה. במפת הקשרים קיימת גם הגדלה עצמאית של גודל הכיתובים, בנוסף לזום הכולל.

כל יכולות V2.6 נשמרו: ארכיון, קריאת ההצגה, השוואת סדרי טקסט ותכנייה, רשתות תוכן ומונחים, הערות, בחירה מרובה, חומרים, קורפוס ומפת אנשים.
