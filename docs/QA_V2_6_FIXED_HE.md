# V2.6 — דוח תיקון תרגום והגדלה (15.10.2026)

## שורש התקלה

**עברית/אנגלית:** בקובץ `assets/js/i18n.js` הייתה פסיקית נוספת במערך זוגות התרגומים. הרצת `new Map(PAIRS)` זרקה `Iterator value undefined is not an entry object`, ולכן מנגנון התרגום לא אותחל כלל. יתרה מכך, החרגת `.reader` מן הסריקה מנעה ממילא תרגום של רכיבי ממשק בתוך הקריאה. הפסיקית הוסרה, רכיבי הממשק של הקורא הוכללו תוך החרגת גוף הטקסט, ונוסף טיפול בתוויות דינמיות, מאפייני נגישות וניסוחים המשולבים עם מספרים.

**זום:** מנגנונים שונים שינו את `transform` של קבוצת צמתים בלבד או רק את רוחב ה־SVG, תוך השארת גובה קבוע. תוקן כך שהגדלה רגילה משנה יחד את הרוחב והגובה של כל ה־SVG ומגדילה באופן יחסי גם צמתים, תוויות, קווים וצירים. נוסף אזור גלילה ייעודי המונע חיתוך, וגם תרשימים המוטמעים ב־CSS grid אינם מאבדים את פריסתם. הגדלת גופן עצמאית עדיין זמינה בנוסף במפת הקשרים.
